📖 Comparative Rules

Level 1 — Short adjectives (1 syllable)

Add -er to the end of the adjective.
If it ends in consonant + vowel + consonant, double the last letter.

tall → taller fast → faster big → bigger small → smaller short → shorter old → older

Level 2 — Adjectives ending in consonant + Y

Drop the -y and add -ier.

happy → happier pretty → prettier busy → busier easy → easier funny → funnier early → earlier

Level 3 — Long adjectives (2+ syllables)

Use more or less before the adjective. Never add -er!

more interesting more expensive more comfortable less crowded less dangerous more exciting

Level 4 — Irregular adjectives

These adjectives have special forms — you must memorise them!

good → better bad → worse far → farther little → less many → more
